Change Control Pipeline

Six display stages, not a state machine (extract §9). A stage is a product label; where it is load-bearing it resolves to the axis beneath it. A HOLD or BLOCK route interrupts the strip and carries that underlying axis with it, so the screen never says a change is “on hold” without saying whether the hold is authority, attempt, evidence, runtime uncertainty or a human decision. Every component is the frozen Day 2 shell; the route interrupt is the one new structure, and it is not a stage.

Five things a hold can be

Extract §9 · the route names its axis
Authority holdThe record beneath AUTHORIZED is no longer ACTIVE, or the evaluation returned HOLD / REJECT. Nothing about the work is asserted.authority · aer-decision
Attempt held or blockedHELD is not failure; BLOCKED is terminal and never restores consumed authority. The boundary outcome is shown beside it.attempt · boundary
Missing evidenceRequired evidence MISSING or PENDING, or SUPPLIED but UNREVIEWED. Which effects it covers is stated, never summarised.evidence-presence · evidence-review
Runtime uncertaintyThe effect set cannot be established. Drawn in ink, not amber: uncertainty is a state, not an alarm.effect-certainty · epistemic
Human dispositionAn accountable person decided HOLD or REJECT after evidence. It lifts only by another human act, whatever the evidence does.disposition

A change can be held for more than one of these at once (chg-0912 has three). The screen lists each; it does not merge them into one “on hold” badge, because lifting one does not lift the others. The route marker takes the colour of its cause — amber or signal only when the underlying state is itself an attention state — and a route is never drawn where no axis records an interruption.

Reference tenant is synthetic. Meridian Logistics, its services, changes, authorities, attempts, evidence records and decisions are invented. The screen declares data-fixture-root="synthetic"; every fixture node is inside it. The seven changes shown were chosen to exercise each route class once and the demo path end to end; that is a coverage choice for a canon artifact, not a claim about how a real register distributes, and no distribution rule exists (extract §11.10). chg-0912 is the same record as on the Command Center (Day 4, under review) and agrees with it in every value.
