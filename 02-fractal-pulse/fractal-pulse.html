CTO OS · Motion System

Fractal Pulse

A loading language derived from the Fractal Core itself. Each of the mark's three frames is a single strokable arc, and each opens at exactly one of its three gates — so progression through the mark is progression through its controls. Nothing rotates. Nothing bounces. Cobalt appears only when the core is accountable.

Derivation

Three arcs,
three gates

Verified against vector master v2 — see the check below the diagram.

The master is not an arbitrary set of rectangles. At stroke width X on the centre lines, the entire structure resolves into exactly three open paths — one per frame, each opened at that frame's own gate. The motion is not applied to the mark; it is read off it.

Route, annotated
01 f1 · Outer frameBounds 0 – 10X. Opens at the top gate — the structure's only opening to the outside. 34 X
02 f2 · Middle frameBounds 1.5 – 8.5X. Opens at the left gate — the core's access channel. 22 X
03 f3 · Inner frameBounds 3 – 7X. Opens at the bottom gate — the evidence channel. 10 X
■ Accountable core4 – 6X, flush inside f3. The only element that may be cobalt, and only while it is active. 2 X

Every arc starts at one edge of its gate and ends at the other, so each stage traces its whole control and returns to the opening it governs. The gate then marks its own passage with a short bar that travels inward through the gap and fades — the connective tissue between stages, and the reason the sequence reads as controls clearing rather than a spinner turning.

Geometry follows VECTOR_CORRECTION_1, Model B: three genuinely distinct nested open frames, uniform X/2 inter-frame gap, core flush inside f3.

Variants

Five states

One rule governs the set: cobalt is present only when the core is genuinely accountable. A held or failed system shows a neutral core.

Break · middle
Error
FractalPulse.Error
The sweep halts mid-arc and the break point turns signal red. The gate never opens; the core never ignites.
Hold is not a spinner that stopped

A hold names the layer. Outer cleared, middle cleared, inner held is a legible statement about where the system is, and the loader should be paired with the reason: Waiting for required evidence or Human decision required.

Colour discipline under failure

Signal red marks only the point where the traverse stopped — never the frames, never the core, and never a gate that did not open. The binding rule from the production board holds in motion exactly as it holds at rest: cobalt is for the core and the OS wordmark only.

Doctrine

Decorative motion is not state

The one rule that outranks every other line on this page.

The loop is decorative. It communicates that work is happening and that the product has a point of view about how work happens. It does not assert that four controls were evaluated, because most of the time the backend has not reported four controls.

Never

Animate stage names against a decorative loop.

// the backend reported none of this
Analyzing…
→ Verifying…
→ Authorized

This manufactures an audit trail out of a CSS keyframe. It is the exact failure CTO OS exists to prevent.

Instead

Bind stages to events, or say nothing.

// decorative — no claim made
<fractal-pulse state="working">
  Working…

// truthful — driven by real events
<fractal-pulse state="hold" hold-at="inner">
  Waiting for required evidence

Generic copy under a decorative loop is honest. Specific copy is a claim, and a claim needs a source.

Practical test before shipping any stage label: if a regulator asked what system event produced this line, is there one? If not, the line is decoration wearing the costume of evidence — and the loader should say Working… instead.

Implementation

Drop-in

Geometry, arc lengths and timing are the contract. Everything else is presentation.

The component ships as a custom element with no dependencies, so it works unchanged in React, Vue or plain HTML. A React wrapper is provided alongside it.

<!-- full master, decorative loop -->
<fractal-pulse state="working" size="120"></fractal-pulse>

<!-- governed hold, driven by a real event -->
<fractal-pulse state="hold" hold-at="inner"></fractal-pulse>

<!-- button-scale, auto-switches to the micro master -->
<fractal-pulse state="working" size="16"></fractal-pulse>
